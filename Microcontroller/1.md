# AVR 8x8 LED Matrix Driver — Explained

## Full Code

```c

#include <util/delay.h>

/* ============================================================
 * TASK SELECTION - set this to the part you're currently
 * working on. Only that task will run in main().
 *   1 = static display
 *   2 = flash

 * ============================================================ */
#define TASK 2       

/* ============================================================

 * ============================================================ */
#define SYMBOL_INDEX        18    // index into alphabet[] -> 0='A', 1='B', 2='C', ...

/*
 * Function to disable JTAG.
 * The ATmega32 reserves some PORTC pins for JTAG by default.
 * Writing a 1 to the JTD bit twice consecutively disables it.
 */
void disable_jtag(void) {
    MCUCSR = (1 << JTD);
    MCUCSR = (1 << JTD);
}

/* ------------------------------------------------------------
 * Core multiplexing routine (used by all three tasks).
 * Scans the 8 rows of `pattern` for approximately duration_ms
 * milliseconds total (rounded down to whole refresh cycles).
 * One full refresh cycle = 8 rows * 2ms = 16ms.
 * ------------------------------------------------------------ */
void display_pattern(uint8_t pattern[8], uint16_t duration_ms) {
    uint16_t cycles = duration_ms / 16;
    if (cycles == 0) cycles = 1; // always show at least one full refresh

    for (uint16_t c = 0; c < cycles; c++) {
        for (uint8_t row = 0; row < 8; row++) {
            // Step A: Turn on the current row (Common Anode requires +5V)
            PORTA = (1 << row);

            // Step B: Turn on the necessary columns for this row.
            // Since columns are cathodes, they require Ground (0) to turn on.
            // We use the bitwise NOT operator (~) to invert the 1s to 0s.
            PORTD = ~pattern[row];

            // Step C: Delay for persistence of vision.
            _delay_ms(2);

            // Step D: Turn off the row and columns before moving to the next
            // to prevent ghosting.
            PORTA = 0x00;
            PORTD = 0xFF;
        }
    }
}

/* ------------------------------------------------------------
 * Blanks the whole matrix (nothing lit) for duration_ms.
 * No multiplexing needed since every LED is off.
 * ------------------------------------------------------------ */
void display_blank(uint16_t duration_ms) {
    PORTA = 0x00;
    PORTD = 0xFF;
    for (uint16_t i = 0; i < duration_ms; i++) {
        _delay_ms(1);
    }
}

/* ============================================================
 * TASK 2: Flash the symbol - on for FLASH_ON_MS, off for
 * FLASH_OFF_MS, repeated `repeats` times.
 * ============================================================ */
void task2_flash(uint8_t pattern[8], uint16_t on_ms, uint16_t off_ms, uint8_t repeats) {
    for (uint8_t i = 0; i < repeats; i++) {
        display_pattern(pattern, on_ms);
        display_blank(off_ms);
    }
}

/* ------------------------------------------------------------
 * Circularly rotate a single row's bits left/right by one
 * position (wraps around within the 8x8 matrix).
 * ------------------------------------------------------------ */
uint8_t rotate_row_left(uint8_t row) {
    return (uint8_t)((row << 1) | (row >> 7));
}

uint8_t rotate_row_right(uint8_t row) {
    return (uint8_t)((row >> 1) | (row << 7));
}

/* ============================================================
 * TASK 3: Rotate the symbol left or right across the matrix.
 * Each row of the pattern is bit-rotated every `step_display_ms`
 * milliseconds, so the whole symbol appears to scroll and wrap
 * around the 8x8 grid. `direction` = ROTATE_LEFT_DIR / ROTATE_RIGHT_DIR.
 * ============================================================ */
void task3_rotate(uint8_t pattern[8], uint8_t direction, uint16_t step_display_ms, uint8_t steps) {
    uint8_t current[8];
    for (uint8_t i = 0; i < 8; i++) {
        current[i] = pattern[i];
    }

    for (uint8_t s = 0; s < steps; s++) {
        display_pattern(current, step_display_ms);

        for (uint8_t row = 0; row < 8; row++) {
            if (direction == ROTATE_LEFT_DIR) {
                current[row] = rotate_row_left(current[row]);
            } else {
                current[row] = rotate_row_right(current[row]);
            }
        }
    }
}

int main(void) {
    // 1. Initialize Ports
    DDRA = 0xFF; // Configure PORTA as output for the rows
    DDRD = 0xFF; // Configure PORTD as output for the columns

    // 2. Disable JTAG to allow full use of PORTC (if it's ever used)
    disable_jtag();

    // The symbol assigned by the lab teacher - change SYMBOL_INDEX above,
    // or swap alphabet[SYMBOL_INDEX] for the `symbol[]` array if you were
    // given a custom pattern instead of a letter.
    uint8_t *active_symbol = alphabet[SYMBOL_INDEX];

    // 3. Run only the task selected by TASK above, forever.
    while (1) {
#if TASK == 1
        // ---- Task 1: Static display ----
        display_pattern(active_symbol, STATIC_DISPLAY_MS);

#elif TASK == 2
        // ---- Task 2: Flash ----
        task2_flash(active_symbol, FLASH_ON_MS, FLASH_OFF_MS, FLASH_REPEATS);

#elif TASK == 3
        // ---- Task 3: Rotate ----
        task3_rotate(active_symbol, ROTATE_DIRECTION, ROTATE_STEP_MS, ROTATE_STEPS);

#else
    #error "TASK must be defined as 1, 2, or 3"
#endif
    }

    return 0;
}
```

## What This Code Does

This is AVR C (targeting an **ATmega32**-family microcontroller) that drives an **8x8 LED matrix** using **row-column multiplexing**. It supports three lab tasks — static display, flashing, and rotating — controlled by a single `#define TASK`.

---

## 1. Clock and Includes

```c
#define F_CPU 1000000UL
#include <avr/io.h>
#include <util/delay.h>
```

- `F_CPU` tells the compiler the MCU's clock speed (1 MHz here), which `_delay_ms()` needs to calculate accurate delays. This must match your actual fuse-bit configuration, or all timing will be off.
- `avr/io.h` gives access to port registers like `PORTA`, `DDRA`, `MCUCSR`.
- `util/delay.h` provides `_delay_ms()` for blocking delays.

---

## 2. Task Selection and Configuration Macros

```c
#define TASK 2
```

This is the "master switch." Only one task's code path compiles into `main()`, selected via `#if/#elif` preprocessor directives further down. Since it's a compile-time constant, unused task code doesn't even end up in the final binary.

The block of `#define`s below it (`SYMBOL_INDEX`, `ROTATE_DIRECTION`, timing constants like `FLASH_ON_MS`) are the knobs you're meant to tweak per lab assignment — letter to display, rotation direction, and how long things stay lit — without touching the logic itself.

---

## 3. The Symbol Data

```c
uint8_t symbol[8] = { ... };
uint8_t alphabet[26][8] = { ... };
```

Each `uint8_t` is one **row** of the 8x8 grid, written as an 8-bit binary literal (`0b...`). A `1` bit means "this LED should be on," `0` means off. Reading top to bottom gives you the 8 rows of the image.

`alphabet[26][8]` is a 2D array: 26 letters, each represented by its own 8-row bitmap, so `alphabet[0]` is `'A'`, `alphabet[25]` is `'Z'`, and so on. `SYMBOL_INDEX` picks which letter to use at runtime.

---

## 4. Disabling JTAG

```c
void disable_jtag(void) {
    MCUCSR = (1 << JTD);
    MCUCSR = (1 << JTD);
}
```

On the ATmega32, four pins of **PORTC** are reserved for JTAG debugging by default. If your matrix wiring ever needs PORTC, those pins stay stuck in JTAG mode unless disabled. The datasheet requires writing a `1` to the `JTD` (JTAG Disable) bit **twice within four clock cycles** as a safety interlock against accidental disabling — hence the same line appearing twice. In this specific program PORTC isn't used, so this call is largely precautionary/leftover, but harmless to keep.

## 5. Core Display Routine: `display_pattern()`

```c
void display_pattern(uint8_t pattern[8], uint16_t duration_ms) {
    uint16_t cycles = duration_ms / 16;
    if (cycles == 0) cycles = 1;

    for (uint16_t c = 0; c < cycles; c++) {
        for (uint8_t row = 0; row < 8; row++) {
            PORTA = (1 << row);
            PORTD = ~pattern[row];
            _delay_ms(2);
            PORTA = 0x00;
            PORTD = 0xFF;
        }
    }
}
```

This is the heart of the whole program — it implements **multiplexed scanning**, the standard technique for driving an 8x8 matrix with only 16 pins instead of 64.

An 8x8 LED matrix's rows are wired as **anodes** (common anode) and columns as **cathodes**. You can only light up one row at a time, but if you cycle through all 8 rows fast enough (~60+ times per second), persistence of vision makes it look like a static image.

Step by step, for each row:
- **`PORTA = (1 << row)`** — turns on exactly one row line (bit-shift creates `00000001`, `00000010`, etc., selecting rows 0 through 7 one at a time). Since it's common-anode, HIGH powers the row.
- **`PORTD = ~pattern[row]`** — the columns are cathodes, meaning they turn an LED on when pulled LOW (0), not HIGH. Since `pattern[row]` stores `1` for "LED on," the code inverts it with `~` so a `1` in the data becomes a `0` on the actual pin — completing the circuit for that LED.
- **`_delay_ms(2)`** — keeps that row lit briefly so the human eye can register it.
- **`PORTA = 0x00; PORTD = 0xFF;`** — before moving to the next row, everything is turned off. Skipping this would cause **ghosting**, where LEDs from the previous row briefly overlap with the next row's activation.

The outer loop (`cycles`) just repeats this 8-row sweep enough times to cover the requested `duration_ms`, since one full sweep is roughly `8 rows × 2 ms = 16 ms`.

## 6. Blanking: `display_blank()`

```c
void display_blank(uint16_t duration_ms) {
    PORTA = 0x00;
    PORTD = 0xFF;
    for (uint16_t i = 0; i < duration_ms; i++) {
        _delay_ms(1);
    }
}
```

Turns everything off and just waits — no multiplexing needed since nothing is lit. Used between flashes in Task 2.

## 8. Task 3 — Rotating: Bit Rotation Helpers

```c
uint8_t rotate_row_left(uint8_t row) {
    return (uint8_t)((row << 1) | (row >> 7));
}

uint8_t rotate_row_right(uint8_t row) {
    return (uint8_t)((row >> 1) | (row << 7));
}
```

These perform a **circular bit rotation** on a single byte (one row), so bits that fall off one end wrap around to the other — this is what makes the symbol appear to scroll and wrap around the matrix rather than just sliding off and disappearing.

- `rotate_row_left`: shifting left by 1 pushes the leftmost bit out (lost from an 8-bit type), so `row >> 7` grabs that same original leftmost bit and reinserts it at the rightmost position via OR.
- `rotate_row_right`: same idea, mirrored — the rightmost bit that falls off gets reinserted at the leftmost position.

```c
void task3_rotate(uint8_t pattern[8], uint8_t direction, uint16_t step_display_ms, uint8_t steps) {
    uint8_t current[8];
    for (uint8_t i = 0; i < 8; i++) {
        current[i] = pattern[i];
    }

    for (uint8_t s = 0; s < steps; s++) {
        display_pattern(current, step_display_ms);
        for (uint8_t row = 0; row < 8; row++) {
            if (direction == ROTATE_LEFT_DIR) {
                current[row] = rotate_row_left(current[row]);
            } else {
                current[row] = rotate_row_right(current[row]);
            }
        }
    }
}
```

- First, the original `pattern` is copied into a working array `current[8]`, so the source symbol data itself is never modified.
- Each of the `steps` iterations: display the current frame for `step_display_ms`, then rotate every row one bit in the chosen direction before the next frame. Since `ROTATE_STEPS` is set to 8 (matching the matrix width), the symbol makes one complete wrap-around cycle.

## 9. `main()`

```c
int main(void) {
    DDRA = 0xFF;
    DDRD = 0xFF;
    disable_jtag();

    uint8_t *active_symbol = alphabet[SYMBOL_INDEX];

    while (1) {
#if TASK == 1
        display_pattern(active_symbol, STATIC_DISPLAY_MS);
#elif TASK == 2
        task2_flash(active_symbol, FLASH_ON_MS, FLASH_OFF_MS, FLASH_REPEATS);
#elif TASK == 3
        task3_rotate(active_symbol, ROTATE_DIRECTION, ROTATE_STEP_MS, ROTATE_STEPS);
#else
    #error "TASK must be defined as 1, 2, or 3"
#endif
    }
    return 0;
}
```

- `DDRA = 0xFF` and `DDRD = 0xFF` configure all 8 pins of **PORTA** (rows) and **PORTD** (columns) as **outputs** (`DDR` = Data Direction Register; `1` bit = output).
- `active_symbol` is a pointer into the `alphabet` array, picked by `SYMBOL_INDEX` — this is how the letter to display gets selected without duplicating code per letter.
- The `#if TASK == ...` block is resolved by the **preprocessor at compile time**, not at runtime — so changing `TASK` and recompiling is what switches behavior; there's no runtime branching or wasted cycles checking which task to run.
- `while(1)` runs the selected task forever, since embedded programs never "return" in normal operation — `return 0;` at the end is unreachable but kept for `main`'s required signature.

## Quick Reference: Hardware Assumptions

| Signal | Port | Direction | Logic |
|---|---|---|---|
| Rows (anodes) | PORTA | Output | Active HIGH (1 = row selected) |
| Columns (cathodes) | PORTD | Output | Active LOW (0 = LED on) |

If your matrix is wired differently (e.g., common cathode rows, or swapped ports), you'd need to adjust the `PORTA`/`PORTD` assignments and the `~` inversion in `display_pattern()` accordingly.
